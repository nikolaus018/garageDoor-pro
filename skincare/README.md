# Glow – Skincare Tracker

Python-Backend (nur Standardbibliothek, SQLite) + HTML-Frontend.

```
cd skincare && python3 server.py   # http://localhost:8000
```

- **Skincare**: eine Checkbox pro Tag, Streak + 7-Tage-Übersicht.
- **Kissenbezug**: frisch bezogen → Nacht 1 (Seite A) → umdrehen → Nacht 2 (Seite B) → neu beziehen.
